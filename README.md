# 银行 EPI 刷题小程序

一个自包含、可离线的银行 EPI（通用就业素质测评）刷题网页。内置 668 道真题，覆盖五大题型：言语理解与表达、判断推理、数字运算、资料分析、思维策略。

## 核心机制：分组刷题 + 错题间隔重复

每次从题库随机抽取 **20 题为一组**。答错的题自动进入**错题集**，并按以下时间线间隔回炉：

| 阶段 | 说明 |
|---|---|
| 第 1 组答错 | 进入错题集 |
| 接下来 2 组 | 该错题不再出现 |
| 第 4 组 | 回炉**复习**（无论答对答错，都不脱离错题集） |
| 再隔 2 组 | 该错题不再出现 |
| 第 7 组 | 回炉**考核**：答对 → 脱离错题集；答错 → 循环回起点 |

考核答对的题才算真正掌握，脱离错题集；考核答错则无限循环复习。

## 记忆方式

进度、错题集、每道题的间隔阶段状态均保存在浏览器本地（`localStorage`）。**同一浏览器**关闭再打开、刷新页面都不会丢失，无需联网、无需账号。清除浏览器数据会同时清空进度。

## 使用方式

- **直接打开**：双击 `index.html` 即可在浏览器中使用（本地离线）。
- **发布为网页**：将本仓库部署到 GitHub Pages（`main` 分支根目录），即可通过链接访问。
- **本地数据不跨设备**：进度存于各浏览器的 localStorage，换设备/浏览器不会自动同步。

## 其他功能

- 按题型分类筛选
- 错题集列表查看（含每题的当前阶段：间隔中 / 待复习 / 待考核）
- 添加自定义题库（单题添加 / 批量导入）
- 题干多分点自动分行显示

## 重新生成（可选）

`index.html` 由 `build.py` 读取 `questions.json` 生成。修改题库后，运行：

```bash
python build.py
```

> 注意：`build.py` 中的输入/输出路径为本地绝对路径，请按需修改 `JSON_PATH` 与 `OUT_PATH`。
